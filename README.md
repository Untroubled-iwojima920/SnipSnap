## 🛠️ How to Use SnipSnap

### Taking Your First Screenshot

1. Click the SnipSnap icon in the menu bar (top-right corner of your screen).
2. Choose **"Capture Screen"**, **"Capture Window"**, or **"Capture Selection"**.
3. If you chose selection, drag your mouse to highlight the area you want to capture.
4. Release the mouse button—your screenshot is now ready.

### Pinning a Screenshot or Window

1. Take a screenshot as described above.
2. Click the **pin icon** that appears on the screenshot toolbar.
3. The screenshot will now stay on top of all other windows. Drag it anywhere, or resize it using the edges.
4. To unpin, click the pin icon again or press **Esc**.

### Extracting Text (OCR)

1. Take a screenshot of any image, document, or screen area containing text.
2. Click the **"Extract Text"** button on the screenshot toolbar.
3. SnipSnap will instantly recognize all text in the image and copy it to your clipboard.
4. Paste it anywhere using **Cmd+V**.

### Translating Text

1. Select any text in any application (browser, document, email).
2. Right-click and choose **"Translate with SnipSnap"**.
3. A small window appears with the translation. Choose your target language from the dropdown menu.
4. Click **"Copy Translation"** to use it elsewhere.

## 🔧 Troubleshooting

**"SnipSnap won't open"**
If macOS blocks the app, go to **System Settings > Privacy & Security**, scroll down to the "Security" section, and click **"Open Anyway"**. This is a one-time step.

**Screenshots aren't saving**
Check your **Screen Recording** permission in System Settings > Privacy & Security > Screen Recording. Make sure SnipSnap has a checkmark next to it.

**OCR is not recognizing text**
Make sure the text is in focus and not blurry. Try increasing the brightness or zooming in on the image before capturing.

**Translation isn't working**
Verify you have an internet connection for translation (unlike OCR, translation uses online services for better accuracy). Also, check that your selected text is correctly highlighted.
